# RV Tycoon

Браузерный вертикальный idle-тайкун в стиле Endless Frontier: 5 рас, 25 героев × 3 формы, крипы, петомцы, подземелья, гильдии.

```
npm install
npm test        # формулы и бой
npm run dev     # http://localhost:5173
```

- Дизайн: `DESIGN.md`
- Для агента: `AGENT.md`
- Стек: `docs/STACK.md` · Экраны: `docs/SCREENS.md` · Сейв: `docs/SAVE_FORMAT.md` · Ассеты: `docs/ASSETS.md`
- БД: `supabase/schema.sql`
