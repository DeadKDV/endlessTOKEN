# Экраны (вертикаль 9:16, логическое разрешение 360×640)

Все размеры — в логических пикселях; канвас масштабируется на весь экран с сохранением пропорций, `image-rendering: pixelated`.

```
┌──────────────────────────┐ 0
│ 💰 золото ⭐ очки 💎 🔮   │ верхняя полоса валют, 40 px
├──────────────────────────┤ 40
│  [HP босса/базы]         │
│                          │
│   бой: отряд ← → мобы    │ сцена боя, 40..440 (PixiJS)
│   земля на y=420         │
│  Этаж 137 · волна 2/3    │
├──────────────────────────┤ 440
│ контент вкладки          │ панель, 440..584 (Svelte, скролл)
│                          │
├──────────────────────────┤ 584
│ Бой Герои Дерев База Подз│ нижняя навигация, 56 px
└──────────────────────────┘ 640
```

| Вкладка | Содержимое панели | Что открывает |
| --- | --- | --- |
| Бой | 4 рекламные кнопки (2×2), полоса быстрой прокачки отряда (портрет, уровень, «▲»), кнопка «Воскрешение» с превью кристаллов, слайдеры состава крипов | — |
| Герои | Список героев в отряде: имя, уровень, форма, кнопка «Улучшить ×1/×10/×max», тап по герою → карточка (статы, 3 способности, петомец, слоты артефактов) | Карточка героя — полноэкранная модалка |
| Деревня | Казармы по расам + Полигон/Лазарет/Знамёнщик: уровень, эффект, стоимость в очках этажа | — |
| База | Шахта/Склад/Таверна/Псарня/Портал; индикатор оффлайн-лимита | — |
| Подземелья | 5 карточек: раса мобов, ресурс, входов осталось, кнопка «Войти» (60 с бой на той же сцене) | Магазин артефактов ветки |
| Гильдия | Нет гильдии → список/создать; есть → рейд-босс (HP, заходы), война (счёт недели, атаки), чат, участники | — |
| Магазин | Самоцветы: призыв, сброс кулдаунов, косметика, пакеты | — |

**Попапы:** оффлайн-доход при входе; подтверждение престижа; яйцо петомца при 10-м этаже; экран «RVPower» на весь экран 3 с при нажатии рекламной кнопки.

**Жесты:** тап по сцене боя — ничего (бой автоматический); долгий тап по кнопке «Улучшить» — автоповтор.

**Над панелью (все вкладки):** полоса «Этаж N · до босса K · лучший M» с шкалой и кнопкой «Остаться» (авто-проход выкл — повтор этажа). Откат после поражения — тост «Откат на этаж N». На кнопках нижней навигации красная точка, если есть доступная покупка (`src/ui/progress.ts`). Док (полоса + панель) начинается с 66% высоты — под землёй сцены (420/640); сцену рисует рендер, её высота от него.
