# Инструкция для агента (Claude Code / Cursor / любой)

Прочитай в этом порядке: `DESIGN.md` → `docs/STACK.md` → `src/data/schema.md` → `docs/SCREENS.md`. Остальное — по мере надобности.

## Что уже есть
- `DESIGN.md` — полный дизайн: цикл, экономика, расы, герои, петомцы, подземелья, монетизация, гильдии, формулы.
- `src/data/` — весь контент в JSON: 25 героев × 3 формы с числами способностей, 15 крипов, здания, 20 артефактов, экономика, словари ru/en.
- `src/sim/` — чистая симуляция: формулы (`economy.ts`), кольцо рас, генерация этажей, детерминированный бой (`battle.ts`), престиж, оффлайн, сборка отряда (`party.ts`). Все формулы из DESIGN.md реализованы и покрыты `tests/`.
- `src/render/BattleView.ts` — PixiJS-сцена 360×640, юниты-прямоугольники (замена на спрайты — `drawUnit`).
- `src/ui/` — Svelte-оболочка: валюты, вкладки, экран героев с прокачкой, 4 рекламные кнопки-заглушки «RVPower», попап оффлайна.
- `src/save/` — localStorage с миграциями и экспортом; Supabase-клиент (anonymous auth, push/pull сейва).
- `supabase/schema.sql` — таблицы, RLS, перечень Edge Functions.

## Что сделать (порядок из DESIGN.md)
1. `npm install && npm test` — тесты зелёные. `npm run dev` — бой идёт, герой качается.
2. Шаги 2–3: остальные вкладки по `docs/SCREENS.md`; Supabase (`.env` от владельца), облачный сейв, Edge Functions из `docs/STACK.md`.
3. Способности героев: `battle.ts` их пока не исполняет. Добавить `applyAbilities(state)` по `kind` из `src/data/schema.md`; реализовать сначала kinds, которые есть у стартовых 5 людей.
4. Дальше по списку «Порядок разработки» в DESIGN.md.

## Правила
- `src/sim/` без DOM и без импортов из `render/ui/save`.
- Числа баланса — только из `src/data/*.json`; не хардкодить.
- Не менять формулы в `economy.ts` без правки DESIGN.md и тестов.
- Ключи Supabase — только через `.env`, не коммитить.
- Спрайты лежат в `src/assets/raw/` (владелец кладёт сам); пока их нет — заглушки.
- Коммиты небольшие, по одному шагу плана.

## Чего нет и кто даёт
| Чего нет | Кто |
| --- | --- |
| Спрайты Elthen | владелец покупает и кладёт в `src/assets/raw/` (см. `docs/ASSETS.md`) |
| `.env` с ключами Supabase | владелец |
| Рекламная сеть | не подключается; провайдер `stub` |
| Макеты экранов пиксельно | агент предлагает по `docs/SCREENS.md`, владелец правит |
